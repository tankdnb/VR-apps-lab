# GitHub Research Wave 267 Plan - Source-Light OpenVR/SteamVR Overlay, Tweak, and HUD Variants

## Goal

Study small OpenVR/SteamVR overlay-related repositories and classify them by
source evidence level, minimal donor value, vendor payload, and product intent.

## Research Questions

- Which overlay candidates contain real implementation evidence?
- Which are README-only, placeholder, or vendor-heavy shells?
- What can a minimal native OpenVR overlay teach about texture submission and
  placement?
- How should MR image-panel demos be classified against native overlay tools?

## Shortlist

- `bwmcadams/vorpal`
- `UpsilonScorpi/VRP-Overlay`
- `LapisGit/OVRTweaks`
- `JasonPKnoll/vr_overlay`
- `pouya-codes/VR_overlay`

## Required Checks

- Deduplicate against OpenVR overlay micro-surfaces, overlay media
  micro-surfaces, and source-light VRChat overlay waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 267.
- Registry and family entries for source-light OpenVR/SteamVR overlay variants.
- Method catalog entry for source-light overlay intake.
- Follow-up gaps around minimal OpenVR texture loops, vendor-heavy Unity
  overlay shells, and MR image-panel UX references.
