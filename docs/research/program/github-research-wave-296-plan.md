# GitHub Research Wave 296 Plan - Spatial Anchors, Colocation, Persistent MR Spaces, and Room Registration

## Goal

Study spatial-anchor and persistent MR-space projects as reusable references for
shared anchors, colocation, room scan persistence, scene registration,
anchor-relative content, stylus/canvas surfaces, and Quest MR utility shells.

## Research Questions

- How do projects separate anchor lifecycle, world alignment, content
  attachment, persistence, sharing, and repair/status UI?
- Which parts are local-only anchors, cloud/shared anchors, MRUK room anchors,
  or explicit registration transforms?
- How do persistent room/scene packages store relocation evidence?
- Which projects are code donors versus product-composition references?
