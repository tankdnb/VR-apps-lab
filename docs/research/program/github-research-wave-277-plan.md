# GitHub Research Wave 277 Plan - VR Rehabilitation, Therapy, and Treatment-Loop Prototypes

## Goal

Study VR rehabilitation and therapy prototypes as reusable references for
calibration, personalized difficulty, sensor input, feedback surfaces, logging,
and clinical/privacy safety boundaries.

## Research Questions

- How do projects model calibration before therapy tasks?
- Which sensor inputs appear: hand tracking, pinch/grasp, Leap, EEG/LSL,
  microphone, or simple web input?
- How are personalized difficulty, haptics, timers, and logs represented?
- Where must medical claims, privacy, and validation caveats stay explicit?

## Required Checks

- Deduplicate against prior training, sensor-loop, accessibility, and
  biometric-bridge waves.
- Sync sources only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Keep engineering reuse separate from therapeutic efficacy claims.

## Expected Outputs

- Landscape synthesis for Wave 277.
- Registry/family entries for VR rehabilitation and treatment-loop prototypes.
- Method catalog entry for rehabilitation treatment-loop boundaries.
- Follow-up matrix around calibration, input confidence, personalized
  difficulty, feedback, logs, and clinical/privacy caveats.
