# GitHub Research Wave 274 Plan - Playspace, Chaperone, Boundary, and Safety-Awareness Utilities

## Goal

Study playspace, chaperone, boundary, and safety-awareness projects that reveal
how VR tools detect safe areas, player movement, intrusions, or passthrough
intervention states.

## Research Questions

- Which runtime, game, or sensor data sources define the safety boundary?
- How do projects model allowed space over time?
- Which interventions are UI/product patterns rather than runtime APIs?
- How do study/research projects log enough evidence for later analysis?
