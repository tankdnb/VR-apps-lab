# GitHub Research Wave 328 Plan - VRChat Communication, Translation, Media, and Notification OSC Companions

## Goal

Study VRChat OSC companion tools that turn speech, translation, media state, or
desktop notifications into bounded in-VR communication surfaces.

## Research Questions

- How do stronger chat/translation companions separate recognition, translation,
  output routing, OSC, and overlay/subtitle surfaces?
- Which smaller media/notification sidecars are useful as lower-bound product
  references?
- What privacy and channel-separation rules should future communication tools
  inherit?
