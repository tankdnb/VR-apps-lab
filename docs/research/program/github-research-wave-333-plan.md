# GitHub Research Wave 333 Plan - WebXR Capability Probes, Pass-Through Testbeds, and Lightweight Utility Labs

## Goal

Study WebXR utility repositories that act as capability probes, pass-through
rendering experiments, AR placement helpers, loading/bounding helpers, and
small lab/index surfaces for WebXR workflows.

## Research Questions

- What can a browser-only XR doctor or capability export page check without a
  native runtime tool?
- How do pass-through and video plane experiments separate feature probing,
  WebGL resource setup, frame loops, and exportable reports?
- Which tiny WebXR helpers are useful product references even when repos are
  thin?

## Shortlist

- `rwth-acis/i5-Toolkit-for-WebXR`
- `gareth-morgan-nv/WebXR-utils`
- `webvrdev/webvrdev-labs`

## Required Checks

- Deduplicate against previous WebXR hand/input/profile/testbed waves.
- Sync source only into local-only cache.
- Read source and documentation statically; do not run, build, install, or
  launch any found project.
- Mark very thin repos as references, not deep code donors.

## Expected Outputs

- Landscape synthesis for Wave 333.
- Registry/family entries for studied projects.
- Method catalog entry for browser XR capability report and utility testbed
  pages.
