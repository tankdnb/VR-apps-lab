# GitHub Research Wave 280 Plan - VR Training, Assessment, Scenario Grading, and Skill-Practice Prototypes

## Goal

Study VR/XR training prototypes as reusable references for scenario state,
task gates, grading, feedback, per-user notes, study metrics, and source-light
training product framing.

## Research Questions

- How do training projects turn scene actions into score or feedback?
- Which task-gating, difficulty, timer, note, and metric-export patterns are
  reusable outside the original subject matter?
- Which repos are code donors, methodology references, asset-heavy references,
  or no-source/README-only nodes?
- What medical, privacy, and validation caveats must stay visible?

## Required Checks

- Deduplicate against prior training, rehab, medical, study, and WebXR waves.
- Sync sources only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory project fields and reusable pattern bridge fields.
- Keep source-light, asset-heavy, license, medical, and privacy caveats explicit.

## Expected Outputs

- Landscape synthesis for Wave 280.
- Registry/family entries for training assessment and skill-practice projects.
- Method catalog entry for training scenario assessment loops.
- Follow-up matrix around case state, task gates, scoring, feedback, notes,
