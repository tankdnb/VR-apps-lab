# GitHub Research Wave 271 Plan - VR Whiteboard, Annotation, and Note-Taking Surfaces

## Goal

Study VR whiteboard, drawing, annotation, and note-taking projects across
browser, WebXR, Unity, and artifact-heavy repository forms.

## Research Questions

- How do projects map pointer/raycast hits into board, texture, object, or
  scene coordinates?
- Which collaboration/transport patterns are reusable?
- How do annotation tools import/export marks, points, text, and timelines?
- Which projects are donor-worthy versus license- or artifact-limited
  references?

## Required Checks

- Deduplicate against browser-native drawing, WebRTC surface-ingress, and XR
  research data lifecycle waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 271.
- Registry/family entries for whiteboard and annotation surfaces.
- Method catalog entry for mark/stroke/annotation reuse boundaries.
- Follow-up gaps around collaborative drawing, remote annotation, and artifact
  hygiene.
