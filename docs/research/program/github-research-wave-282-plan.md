# GitHub Research Wave 282 Plan - Spatial Audio, Acoustic Accessibility, and Voice Presence Surfaces

## Goal

Study VR/XR audio projects as reusable references for positional audio,
BRIR preprocessing, accessibility-first acoustic navigation, echo/object
description UX, voice presence, VAD, and microphone/privacy caveats.

## Research Questions

- How do browser/VR projects attach listeners, positional sources, and audio
  playback lifecycle to XR sessions?
- How can audio become a primary navigation and accessibility surface rather
  than background ambience?
- Which voice-presence pieces are reusable for companion surfaces or shared VR
  workspaces?
- Which search results are off-theme media conversion nodes rather than audio
  donors?

## Required Checks

- Deduplicate against prior immersive media, AudioLink, sound-trigger, and
  accessibility waves.
- Sync sources only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory project fields and reusable pattern bridge fields.
- Keep microphone, accessibility, bundled-asset, and off-theme caveats explicit.

## Expected Outputs

- Landscape synthesis for Wave 282.
- Registry/family entries for spatial audio and acoustic accessibility surfaces.
- Method catalog entry for spatial audio/acoustic accessibility.
- Follow-up matrix around positional sources, BRIR preprocess, onboarding,
  hints, echo/object descriptions, voice VAD, and interruption recovery.
