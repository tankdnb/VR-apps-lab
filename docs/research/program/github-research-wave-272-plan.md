# GitHub Research Wave 272 Plan - VR File, Local Asset, and VRM Browser Surfaces

## Goal

Study VR file browser, local asset catalog, and runtime import projects that
show how users can choose, classify, preview, import, or manipulate local
files from VR-oriented tools.

## Research Questions

- How do projects represent folders and files in VR or companion UIs?
- Which parts are useful for runtime local import, especially VRM/avatar
  ingestion?
- Where do destructive operations require confirmations, undo, or safer
  sandboxing?
- Which projects are donor-worthy versus source-light or artifact-heavy
  references?

## Shortlist

- `NaruAkitsuki/VrmFileManager`
- `AkiMoriDev/VRC-Files-Manager`
- `SirSerl/VRFileManager`
- `agoetschm/vr_file_browser`
- `Vode1969/vr-file-browser`
- `hunterdquant/Seeker`

## Required Checks

- Deduplicate against VRChat resource/package discovery, creator workbench, and
  browser-native asset browser waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, and indexes.

## Expected Outputs

- Landscape synthesis for Wave 272.
- Registry/family entries for VR file and local asset browser surfaces.
- Method catalog entry for local file/asset browser pipelines.
- Follow-up gaps around permission gates, safe operations, and metadata-backed
  catalogs.
