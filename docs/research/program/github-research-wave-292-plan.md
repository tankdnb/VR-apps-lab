# GitHub Research Wave 292 Plan - VR Comfort Tunnelling, Cybersickness Scoring, and Comfort Profile Utilities

## Goal

Study VR comfort utilities as reusable references for tunnelling/vignette
rendering, cybersickness scoring, adaptive comfort state, user comfort
profiles, and foveated-rendering comfort controls.

## Research Questions

- How do projects separate motion input, comfort scoring, intervention policy,
  and visual effect rendering?
- Which settings belong in a reusable player comfort profile?
- What should be exposed as user-facing controls versus developer defaults?
- Which comfort/performance ideas are donor-quality and which are only
  source-light references?

## Required Checks

- Deduplicate against earlier locomotion, comfort, accessibility, and foveation
  waves.
- Sync sources only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory project fields and reusable pattern bridge fields.
- Keep validation, user-control, symptom-privacy, and source-light caveats
  explicit.

## Expected Outputs

- Landscape synthesis for Wave 292.
- Registry/family entries for comfort/tunnelling/profile utilities.
- Method catalog entry for VR comfort intervention and profile boundaries.
- Follow-up gaps around comfort matrices and profile/import UX.
