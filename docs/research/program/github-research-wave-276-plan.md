# GitHub Research Wave 276 Plan - WebXR Museum, Guided-Tour, and Artifact-Gallery Surfaces

## Goal

Study WebXR and VR museum/gallery projects as reusable references for content
schemas, artifact preview shells, spatial media slots, annotations, guided
exhibits, AR/WebXR viewer adapters, and repository hygiene caveats.

## Research Questions

- How do projects separate exhibit metadata from scene/viewer code?
- Which patterns work for spatial photo frames, portals, annotations, and
  guided content?
- How do museum tools handle desktop, AR, WebXR, and Quest-like paths?
- Which repos are architecture donors versus source-light or artifact-heavy
  references?

## Required Checks

- Deduplicate against prior WebXR, media surface, browser projection, and
  source-light evidence waves.
- Sync sources only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 276.
- Registry/family entries for museum and artifact-gallery surfaces.
- Method catalog entry for museum/gallery artifact surface pipelines.
- Follow-up matrix around manifests, exhibit schemas, frame slots, portals,
  annotations, AR anchors, cleanup, and artifact hygiene.
