# GitHub Research Wave 263 Plan - VRChat Overlay, World Editor, and Udon Microtools

## Goal

Study source-light VRChat utility projects and classify their reusable value
without over-promoting template-derived or artifact-heavy repositories.

## Research Questions

- How should small VRChat projects be classified by surface: overlay, editor,
  world editor, Udon runtime, or package template?
- Which projects reveal reusable microtool patterns despite limited scope?
- Which artifacts, SDK age, or stale API assumptions should block direct code
  reuse?

- `o0F-0oF/vrchatoverlay`
- `kizuki1749/VRChatOverlay`

- `Zaknin/VRCTools`

- `PeaceKunihiro/vrchat-udon-tools`

## Required Checks

- Deduplicate against overlay micro-surfaces, creator diagnostics, Udon-menu,
  and VPM/template waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 263.
- Registry section and family entry for source-light VRChat overlay/editor/world
  microtools.
- Method catalog entry for source-light utility triage and reuse
  classification.
- Follow-up gaps around artifact hygiene, editor diagnostics, Udon sync, and
  overlay/log privacy.
