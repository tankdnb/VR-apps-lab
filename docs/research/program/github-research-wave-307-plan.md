# GitHub Research Wave 307 Plan - XR Gaze, Pinch, Dwell, Onboarding, and Android XR Interaction Samples

## Goal

Study XR gaze, pinch, dwell, guide-card, accuracy-test, and Android XR
interaction samples as reusable references for controller-free UI, accessible
selection, menu confirmation, onboarding, telemetry, and platform capability
state.

## Research Questions

- How do projects separate gaze/eye/camera ray providers from target
  interactable contracts?
- Which reticle, dwell, pinch, controller-confirmation, and cancel/reset
  patterns are reusable?
- How are radial/pie menus, guide cards, questionnaires, attention monitoring,
  and accuracy tests connected to interaction state?
- How do platform permission/status dashboards change the product shape of
  gaze and gesture interactions?

## Shortlist

- `DFKI-Interactive-Machine-Learning/de.dfki-iml.xr-gaze-interaction-toolkit`
- `tomazsaraiva/unity-gaze-interaction`

## Required Checks

- Deduplicate against earlier eye tracking, hand gesture, menu/control, and
  Android XR sample waves.
- Sync sources only into local-only cache.
- Read source and documentation statically; do not run, build, install, or
  launch found projects.
- Keep vendor, license, sample-only, permission, privacy, and dwell-bug
  caveats explicit.

## Expected Outputs

- Landscape synthesis for Wave 307.
- Registry/family entries for gaze, pinch, dwell, onboarding, and Android XR
  interaction samples.
- Method catalog entry for gaze/pinch/dwell interaction boundaries.
- Follow-up gaps around GTK menus/questionnaires, Android XR UI samples, and
  gaze interaction matrices.
