# GitHub Research Wave 261 Plan - VRChat Expression Menu Authoring, Visualization, and Runtime Menu Helpers

## Goal

Study VRChat expression-menu and avatar-menu utilities that help creators
generate, merge, visualize, and repair menu-related assets.

## Research Questions

- Which parts of menu tooling are safe creator-time authoring patterns?
- How do projects manage icons, parameters, animator layers, generated assets,
  ModularAvatar items, and menu page limits?
- Which runtime quick-menu modifications should stay caveated as historical
  references rather than reusable code?

## Required Checks

- Deduplicate against radial-menu, Udon-menu, VRCFury, avatar composition, and
  creator workflow waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 261.
- Registry section and family entry for expression-menu authoring and runtime
  menu helper references.
- Method catalog entry for expression-menu authoring pipelines.
- Follow-up gaps around generated assets, preview/Undo, parameter budget,
  runtime patch caveats, and ModularAvatar/native menu boundaries.
