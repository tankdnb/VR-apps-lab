# GitHub Research Wave 270 Plan - VRChat Asset, Resource, Package Discovery, and Listing Surfaces

## Goal

Study VRChat creator discovery surfaces and package-listing workflows: static
asset indexes, resource websites, graph browsers, A-Frame asset browsers, VPM
listings, and package templates.

## Research Questions

- How do projects represent searchable asset/package metadata?
- Which UI patterns make install, preview, and provenance clear?
- What separates catalog data, presentation, package generation, and install
  action?
- Which search results are false positives or security risks?

## Required Checks

- Deduplicate against VPM publication, VRChat creator-helper, and external
  content-ingress waves.
- Clone only into local-only cache.
- Read source statically; do not run, build, install, or launch projects.
- Extract mandatory fields and reusable pattern bridge fields.
- Classify false positives explicitly.
- Update registry, families, methods, not-yet-studied, current focus, and
  indexes.

## Expected Outputs

- Landscape synthesis for Wave 270.
- Registry/family entries for VRChat resource/package discovery surfaces.
- Method catalog entry for asset/resource/package discovery boundaries.
- Follow-up gaps around catalog schema, VPM UX, and security hygiene.
