# Methods Catalog

This folder extracts reusable `methods`, `patterns`, and `approaches` from the
tracked repositories.

The point is to answer a different question than the project registry:

- not only "which repos do we know?"
- but also "which ways of building VR utilities have already been observed and
  validated across the ecosystem?"

## Files

- `vr-utility-methods-catalog.md`  
  Canonical catalog of methods and implementation approaches that can be used
  when designing new VR tools inside `VR-apps-lab`.

## Method entry convention

Existing method entries do not need to be rewritten.

For future methods, keep the current readable shape:

- `What it is`
- `Good for`
- `Why it matters`
- `Strong references`
- `Best fit for VR-apps-lab`

When it adds signal, also include:

- `Source evidence`
- `Reusable core`
- `Do not copy directly`
- `Maturity`

Suggested maturity values:

- `Observed`
- `Validated by multiple repos`
- `Historical`
- `Prototype-ready`

Use `../program/project-information-and-reuse-patterns-audit.md` for the audit
that introduced this convention.
